# String_Operations
 
 [`BasicToDo.py`](./BasicToDo.py) | A simple task/to-do list program using basic string input and list operations. |

| [`Count_Occurance.py`](./Count_Occurance.py) | Counts the occurrences/frequencies of character within an input string. |

| [`count_occurrence2.py`](./count_occurrence2.py) | An alternative/enhanced implementation for calculating All Characters like vowels, Consonants etc. in a Given sentence or string . |

| [`Day_Greetings.py`](./Day_Greetings.py) | Generates dynamic daily or time-based greeting messages based on string inputs. |

| [`Title_Case.py`](./Title_Case.py) | Converts input strings into title casing format by capitalizing the first letter of each word while keeping other characters lowercase. |

| [`vovelfilter.py`](./vovelfilter.py) | Parses an input string to extract vowels and consonants separately, displaying their exact counts and total character length. |
